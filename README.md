# projeto-aplica-o-web-CRUD
projeto criado por meio de um tutorial e suporte dados pelo professor em sala de aula. Um aplicativo web profissional em Java, responsável por
gerenciar registros de produtos em um banco de dados relacional. Implementaremos as quatro operações fundamentais do padrão CRUD (Create, Read, Update e Delete).
